Crear un usuario:
http://localhost:3006/gestorRestaurantes/api/v1/users/create


Menus:

Crear menu:
POST http://localhost:3006/gestorRestaurantes/api/v1/menus

{
  "menuName": "Hamburguesa Clásica",
  "menuDescription": "Hamburguesa con queso, lechuga y tomate",
  "menuPrice": 45.50,
  "menuCategory": "Comida Rápida",
  "restaurantId": 1
}

listar menu:
GET http://localhost:3006/gestorRestaurantes/api/v1/menus

actualizar menu:
PUT http://localhost:3006/gestorRestaurantes/api/v1/menus/id

Eliminar menú
DELETE http://localhost:3006/gestorRestaurantes/api/v1/menus/id


RESTAURANTS:

Crear restaurante:
POST http://localhost:3006/gestorRestaurantes/api/v1/restaurants

{
  "restaurantName": "La Buena Mesa",
  "address": "Zona 1, Ciudad de Guatemala",
  "phone": "5555-1234",
  "email": "labuenamesa@gmail.com"
}


Listar restaurantes:
GET http://localhost:3006/gestorRestaurantes/api/v1/restaurants

Actualizar restaurante:
PUT http://localhost:3006/gestorRestaurantes/api/v1/restaurants/id


Eliminar restaurante:
DELETE http://localhost:3006/gestorRestaurantes/api/v1/restaurants/id



Tables:

{

  "available": true,

}

Eliminar mesa:
DELETE http://localhost:3006/gestorRestaurantes/api/v1/tables/id
